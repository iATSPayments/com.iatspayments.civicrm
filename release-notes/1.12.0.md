# iATS CiviCRM Extension 1.12.0

Sep 23, 2026

This release is a maintenance release for the 1.x series. 

It is recommended for all CiviCRM installs on 5.81 and above. 

The most significant change is the conversion of many iATS things into real entities, allowing for searchkit functionality.

Thanks @seamuslee001 ! Also thanks to coleman for the update of the old array syntax.

It also includes some important fixes to the return values of successful transactions - if you're running a previous version, it may not mark contributions as complete even when they are.
